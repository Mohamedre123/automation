# تدفّق (Tadfuq) - منصة أتمتة سيناريوهات العمل

منصة أتمتة مرئية على طريقة Make وn8n، مكتوبة من الصفر بالكامل: محرر سيناريوهات، محرك تنفيذ، AI Agent شغال بأي مزوّد (Gemini / ChatGPT / Claude)، Webhooks، جدولة، حسابات متشفّرة، سجل تشغيل، و12 تيمبلت جاهزة.

## التشغيل محلياً

محتاج Node.js 22 أو أحدث.

```bash
npm install
npm run dev
```

- الواجهة: http://localhost:5173
- الـ API والـ Webhooks: http://localhost:3000

محلياً مفيش أي إعدادات مطلوبة: قاعدة البيانات Postgres مدمجة (PGlite) بتتعمل في `server/data`.

## النشر على Vercel + Supabase (مجاناً)

**1. قاعدة البيانات:** اعمل مشروع على [Supabase](https://supabase.com)، ومن `Connect` انسخ رابط **Transaction pooler** (بورت 6543).

**2. اربط الريبو بـ Vercel** وحط متغيرات البيئة دي:

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | رابط Supabase (بورت 6543) |
| `APP_SECRET` | نص عشوائي طويل. **متغيّروش بعد التشغيل** لأنه بيشفّر مفاتيح العملاء |
| `PUBLIC_URL` | رابط موقعك، مثلاً `https://tadfuq.vercel.app` |
| `CRON_SECRET` | نص عشوائي - بيحمي رابط الجدولة |
| `ALLOW_SIGNUP` | `true` عشان أي حد يقدر يعمل حساب، أو `false` لو عايز المنصة ليك بس |

لتوليد المفاتيح:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

**3. الجدولة:** خطة Vercel المجانية بتشغّل الـ Cron مرة واحدة في اليوم بس. عشان السيناريوهات المجدولة تشتغل كل دقيقة، اعمل حساب مجاني على [cron-job.org](https://cron-job.org) وخلّيه يطلب كل دقيقة:

```
https://YOUR-DOMAIN/api/cron/tick?secret=CRON_SECRET
```

**4. أول حساب:** افتح الموقع وسجّل حساب جديد (البيانات المحلية مش بتتنقل). ضيف مفاتيحك من صفحة «الحسابات».

### إزاي المنصة بتشتغل من غير سيرفر دايم

| المحفّز | على Vercel | محلياً |
|---|---|---|
| Webhook | الطلب بيجي على `/webhook/:path` ومنه بيتشغل السيناريو | نفس الشيء |
| تيليجرام | تيليجرام بيبعت التحديثات على الـ Webhook بتاعنا (`setWebhook` وقت التفعيل) | السيرفر بيسأل تيليجرام كل شوية (polling) |
| جدولة | `next_run_at` في قاعدة البيانات + طلب على `/api/cron/tick` | نفس الشيء + مؤقّت داخلي كل 20 ثانية |
| «تشغيل مرة» | جلسة تجربة في قاعدة البيانات، أول طلب يوصل بيتنفّذ عليها | نفس الشيء |

> البوت الواحد بيستقبل من مكان واحد بس. لو شغّلت نفس البوت محلياً وعلى Vercel هيتضارب - استخدم بوت تجربة منفصل.

## التطبيقات المدمجة

| التطبيق | الخطوات المتاحة |
|---|---|
| واتساب (WasenderAPI) | استقبال الرسايل + إرسال نص/صورة/فيديو/ملف |
| واتساب الرسمي (Meta Cloud API) | استقبال الرسايل + إرسال نص/صورة |
| تيليجرام | استقبال الرسايل + إرسال رسالة/صورة + «بيكتب...» |
| فيسبوك | نشر بوست أو صورة على الصفحة |
| إنستجرام | نشر صورة بتعليق (حساب بيزنس) |
| الذكاء الاصطناعي | رد/كتابة، AI Agent بأدوات وذاكرة، وتوليد صور |
| Webhooks | استقبال من أي موقع أو نظام + رد مخصص (API خاص بيك) |
| HTTP | نداء أي API في الدنيا |
| جدولة ومخزن بيانات وشروط | تحكم كامل في المسار |

الصور المتولّدة بتتخزن وبتاخد رابط عام (`/media/:id`) عشان إنستجرام وواتساب يقدروا يجيبوها.

## الحماية

- حدود طلبات محفوظة في قاعدة البيانات (شغالة على Vercel): الدخول (8 محاولات لكل حساب / ربع ساعة)، التسجيل (5 لكل جهاز / ساعة)، الـ Webhooks (`WEBHOOK_RATE_PER_MINUTE` لكل رابط)، رفع صور الفورم، المساعد الذكي، اختبار الحسابات، و600 طلب في الدقيقة لكل حساب.
- حد يومي للتشغيلات (`MAX_EXECUTIONS_PER_DAY`) وحد لعدد السيناريوهات (`MAX_WORKFLOWS_PER_USER`).
- على Vercel خطوات HTTP والخدمات الخارجية مش مسموح لها تكلم عناوين داخلية (SSRF).
- Security headers على الـ API والموقع، والمفاتيح متشفّرة AES-256-GCM، والجلسات متخزّنة كـ hash.

## الذكاء الاصطناعي

في خطوتين:
- **كتابة / رد بالذكاء الاصطناعي** (`ai.generate`): رد، تلخيص، ترجمة، تصنيف، كتابة محتوى.
- **AI Agent** (`ai.agent`): بيفكر ويستخدم أدوات (طلبات HTTP، حفظ وقراءة من مخزن البيانات، الوقت)، وبيفتكر المحادثة لكل عميل لوحده، وبيلتزم بمعلومات شركتك اللي بتكتبها في خانة Knowledge.

الاتنين شغالين بأي مزوّد - العميل بيختار الحساب اللي عنده مفتاحه:

| المزوّد | ملاحظات |
|---|---|
| Google Gemini | فيه طبقة مجانية - الأنسب للبداية. المفتاح من [AI Studio](https://aistudio.google.com/apikey) |
| OpenAI (ChatGPT) | محتاج رصيد مدفوع |
| Anthropic Claude | خطوة «اسأل Claude» كمان موجودة للمهام اللي محتاجة Claude تحديداً |

## هيكل المشروع

```
server/src/
  engine/        محرك التنفيذ: executor، expressions ({{1.message.text}})، queue
  nodes/         التكاملات: core، ai، llm (مزوّدي الذكاء الاصطناعي)، anthropic، http، telegram
  triggers/      تفعيل المحفّزات، استقبال الـ Webhooks، الجدولة، جلسات التجربة
  routes/        الـ API
  db.ts          Postgres (Supabase) أو PGlite محلياً + نقل البيانات القديمة من SQLite
  app.ts         بناء السيرفر | index.ts سيرفر دايم | vercel.ts دالة Vercel
web/src/
  editor/        محرر السيناريو (React Flow): الخطوات، لوحة الإعدادات، منتقي المتغيرات
  pages/         لوحة التحكم، التيمبلت، الحسابات، سجل التشغيلات، مخزن البيانات
```

## إضافة تكامل جديد

1. اعمل ملف في `server/src/nodes/` يصدّر `NodeDefinition[]` (وكمان `CredentialType` لو التطبيق محتاج مفتاح).
2. سجّله في `server/src/nodes/index.ts`.
3. خلاص - الواجهة بتبني فورم الإعدادات لوحدها من تعريف الحقول (`fields`).

## الربط بين الخطوات

أي حقل يقبل متغيرات:
- `{{1.message.text}}` مخرجات الخطوة رقم 1
- `{{2.items[0].name}}` عنصر من مصفوفة
- `{{$now}}` و`{{$today}}` و`{{$execution.id}}` متغيرات النظام
